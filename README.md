# Session Generator Bot

A simple bot to generate Pyrogram/Pyrofork string sessions for your Telegram accounts.

## Features

- Generates String Sessions easily.
- Supports API ID and API HASH authentication.
- Sends the session string directly to your Saved Messages for security.
- Automatically deletes the bot message after 60 seconds.

## Requirements

- Python 3.13+
- Pyrofork
- Pyromode
- python-dotenv

## Deployment

1. Install requirements using `pip install -r requirements.txt`.
2. Set up your config.py file with your API credentials.
3. Run `python bot.py` to start the bot.
