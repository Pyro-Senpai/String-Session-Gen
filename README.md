## Hey There, This is Session Generator Bot! 🚀

Session Generator Bot is an easy-to-use tool to generate secure Pyrogram and Pyrofork string sessions for your Telegram accounts. 

## What is Session Generator Bot?

It allows you to generate string sessions quickly by providing your API ID and API HASH without any hassle. The session is directly sent to your Saved Messages to ensure 100% security.

## Features

- **String Session Generation:** Generate secure Pyrogram/Pyrofork string sessions.
- **Secure Delivery:** The generated session string is forwarded directly to your personal "Saved Messages" chat.
- **Auto-Deletion:** The messages sent by the bot are automatically deleted after 60 seconds for enhanced privacy.
- **2FA Support:** Handles Two-Factor Authentication passwords safely during generation.

## Commands

Here are the commands you can use with this bot:

- `/start` - Start the bot and show the main menu.
- `/string` - Start the session generation process.

## Environment Variables

The following variables are required to deploy your bot:

- `API_ID` - Get this from my.telegram.org
- `API_HASH` - Get this from my.telegram.org
- `BOT_TOKEN` - Get this from @BotFather
